# AI & Machine Learning in Healthcare Report

This repository contains a group research report on the use of artificial intelligence and machine learning in healthcare applications.

## Overview

The report explores how AI and machine learning are being used in healthcare, with a focus on diagnostics, disease prediction, medical imaging, and broader healthcare improvement. It also discusses the related security, ethical, and social issues involved in adopting these technologies.

## Contents

- Final group research report in PDF format
- Supporting figures or diagrams used in the report
- Brief project summary and context

## Report topics

- Introduction to AI and machine learning in healthcare
- Literature review of current applications
- Examples of healthcare use cases, including cancer detection and predictive analysis
- Security, ethical, and social issues
- Conclusion and reflection on the group activity

## Module context

This report was completed as part of **CO1101 Computing Fundamentals** at the **University of Leicester** as a group coursework submission.
